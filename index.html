02 / BEHIND THE PROJECT

A storefront with
the essentials.

The original Blossom project is a PHP and MySQL accessories store. Visitors can browse by category, view product details, see discounts and stock status, add items to a cart, and continue to checkout. It also includes account and administration screens.

This static portfolio demo presents the visitor-facing catalogue with the project’s sample records. Bag changes stay in this browser only.
